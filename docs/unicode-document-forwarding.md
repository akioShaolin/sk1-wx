## Contract and minimal correction

The installed Windows launcher calls bundled `unicode_sys_argv()`, which
uses GetCommandLineW/CommandLineToArgvW and supplies Python 2 Unicode values.
`normalize_sys_argv()` expands/absolutizes them without encoding to bytes.
The original `check_server()` interpolated Unicode into a string and passed
it to binary `write()`, implicitly requiring ASCII. Accented names failed.

`src/sk1/__init__.py` now encodes only Unicode arguments to UTF-8 before the
existing write. Already encoded UTF-8/ASCII byte paths remain unchanged.
The newline-delimited wire format, spaces, ordering, timeout, timer and
lock/socket lifecycle are unchanged. No quotes, BOM or new protocol are added.

The unmodified real `AppFileWatcher.on_timer()` reads bytes, removes the
newline and passes the same UTF-8 bytes to fsutils.exists and app.open.
Inspection of the actual bundled fsutils bytecode confirmed that Windows
`upath()` decodes UTF-8 bytes to Unicode, retaining Unicode inputs; uopen and
exists call upath. Application.open retains an internal byte-path contract,
including `str(os.path.dirname(doc_file))`. Decoding at that entry would
introduce another implicit Python 2 ASCII conversion, so no receiver change
is needed. Application.open and all save code were read-only in this task.

## Deterministic regressions

`tests/test_document_forwarding.py` executes the real sender and real receiver
methods against temporary files and real binary I/O. It models the inspected
fsutils conversion and stubs GUI services. Replacing the sender's sleep with
a synchronous receiver callback coordinates consumption without timed waits.
Tests assert exact wire bytes, delimiter, delivered types/paths/order, zero
sender exit, socket removal and retained lock.

Cases cover Unicode accented filenames, accented parent directories with
spaces, Chinese filenames, UTF-8 bytes, ASCII bytes and mixed multiple paths.
The Chinese test is transport coverage, not a claim of full GUI support.

Before the production change, the six focused tests had four UnicodeEncodeError
failures and two passing byte-path cases. After the two-line change, all six
passed as part of the full 33-test suite. An initial harness attempt needed
to retain the loaded receiver module to prevent Python 2 clearing its globals;
the failure-before result above uses the corrected harness.
